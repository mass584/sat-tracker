# Sat Tracker

肉眼で見える明るさの人工衛星を、地図・時刻・空の3方向から探すブラウザアプリです。

- 世界地図上の現在位置と地上軌跡を見る
- 過去・未来の任意の時刻へ移動して、軌道の動きを追う
- 任意の地点から次に肉眼で見えるタイミングを計算する
- 見たいタイミングを保存し、その時刻にカメラをかざして空の中から探す

**→ https://mass584.github.io/sat-tracker/**

ビルド不要・依存はすべてローカル同梱・アカウント不要です。

## 使う

上のURLをそのまま開けば動きます。HTTPS配信なので、「現在地を使う」もARビューも利用できます。
スマートフォンでホーム画面に追加するとアイコン付きで起動できます。

## ローカルで動かす

```sh
python3 -m http.server 8123      # リポジトリのルートで実行
# → http://localhost:8123/
```

`index.html` を直接開く（`file://`）でも地図と計算は動きますが、位置情報とカメラは
`https` か `localhost` でのみ使えるため **`http://localhost` を推奨**します。

**未コミットの変更**をスマートフォンの実機で試したいときは、一時的なHTTPSトンネルを張ります
（公開済みの内容を試すだけなら上のURLで足ります）。

```sh
cloudflared tunnel --url http://localhost:8123     # https://xxx.trycloudflare.com が発行される
```

このトンネルはローカルサーバーを公開インターネットに晒すので、確認が済んだら `Ctrl-C` で止めてください。

## 機能

### 追跡対象

ヘッダーのセレクトボックスから8件を選べます。軌道要素は CelesTrak の「visual」群
（肉眼で見える明るさの人工天体 約157個）から取得し、そのうち**標準等級が分かっているもの**を
追跡対象にしています。

| 対象 | NORAD | 標準等級 | 特徴 |
| --- | --- | --- | --- |
| 国際宇宙ステーション ISS | 25544 | −1.8 | 最も明るい。高度約430km、軌道傾斜51.6° |
| 中国宇宙ステーション 天和 CSS | 48274 | −0.5 | 軌道傾斜41.5°で、日本からはISSより低空 |
| ハッブル宇宙望遠鏡 HST | 20580 | 1.5 | 軌道傾斜28.5°。日本からは南の低空のみ |
| エンビサット | 27386 | 1.7 | 退役した大型衛星。太陽同期軌道で薄明時の可視機会が多い |
| テラ / アクア | 25994 / 27424 | 2.4 | 地球観測衛星（太陽同期軌道） |
| あじさい | 16908 | 2.5 | 高度1490km。鏡面反射で瞬間的に強く光る |
| だいち2号 ALOS-2 | 39766 | 2.7 | 陸域観測技術衛星 |

選択は次回起動時に復元されます。軌跡・可視円・周回周期・タイミング計算はすべて追随します。

### 地図

正距円筒図法に、現在位置・前後1周回分の地上軌跡・可視円（フットプリント）・昼夜境界・
太陽直下点・観測地点を描きます。

- **ドラッグで横スクロール**します。経度は周期的なので何周でも回せます
- **クリックで観測地点を設定**します（移動4px未満をクリックとみなします）
- スクロールすると右上に「表示位置を戻す」が出ます

### 時刻の移動

LIVE（実時間追従）／スライダー（±12時間）／基準日時の直接指定／ワンタッチ移動
（±10分・±1時間・±1日）／再生（×1〜×1800）。過去も未来も同じ方法で計算しているので精度は同じです。

### 次に見えるタイミングを探す

観測地点（現在地・都市プリセット・地図クリック）から、今後3〜14日間の通過を計算します。
結果は早いものから3件ずつ表示され、「さらに未来の結果も表示」で増えます。

「肉眼で見えるものだけ」は、次の4条件をすべて満たす時間帯だけに絞り込みます。

1. 衛星が太陽光を浴びている（地球の影に入っていない）
2. 観測地の太陽高度が −6°より低い（市民薄明より暗い）
3. 衛星が地平線より上にある
4. 見かけの等級が「空の条件」の限界より明るい

「空の条件」は **市街地 3.0等 / 郊外 4.5等 / 暗い空 5.5等**（既定は郊外）です。

### 保存とARビュー

各カードの「☆ 保存」でタイミングを保存すると、ヘッダーの★アイコンから開くダイアログに並びます。

- 終わったものは既定で隠れ、「過去の記録も表示」で末尾に出ます
- 終了から**30分はまだ「これから」の扱い**（終わった直後に消えると使いにくいため）、
  7日間保持したのち自動削除します
- 地点名の部分を押すと、その座標を観測地点として地図に反映します
- 「📷 ARで探す」で全画面のARビューが開き、背面カメラの映像に衛星の方向を示す照準・
  通過の経路・画面外への矢印を重ねます

## 精度と割り切り

### 位置

最新TLE + SGP4（satellite.js v5）で計算しています。取得直後は実測との差が数km以内、
TLEの元期から離れるほど誤差が増えます（数日で数十km程度）。
ISS選択時のみ wheretheiss.at と30秒ごとに自動照合し、差をⓘダイアログに表示します。

### 明るさ

```
等級 = 標準等級 − 15.75 + 2.5·log10(距離² ÷ 位相関数) + 大気減光
```

位相関数は太陽・衛星・観測者のなす角から求め、大気減光は Pickering の大気路程に
0.28等/大気路程を掛けています。

**標準等級は観測者コミュニティの概算値で、確度が高いのはISSくらいです。**
姿勢による見かけの変化（太陽電池パネルの向き、鏡面反射によるフレア）は考慮していません。
あじさいは実際には計算値より瞬間的に明るく光ることがあります。

### その他

- 通過の探索は20秒刻み、地平線通過は二分法で1秒未満、最大仰角は三分探索、可視判定は10秒刻み
- 太陽位置は低精度モデル（誤差1分角未満）で、昼夜・可視判定には十分です
- 地球の影は円筒モデルで、半影（影の出入りの数十秒かけた減光）は再現しません
- 大気差（地平線近くの浮き上がり）は未考慮です。低仰角の通過は実際よりわずかに早く昇り遅く沈みます

## データの出どころ

| 用途 | ソース |
| --- | --- |
| 軌道要素 | CelesTrak `GROUP=visual`（6時間ブラウザにキャッシュ） |
| 計算値の健全性チェック | `https://api.wheretheiss.at/v1/satellites/25544`（ISS選択時のみ） |
| 世界地図 | Natural Earth 110m land（パブリックドメイン、`world-land.js` に同梱） |
| SGP4実装 | satellite.js v5.0.0（MIT、`vendor/` に同梱） |

ネットワークが使えない場合は `app.js` の `FALLBACK_TLE`（ISSのみ）にフォールバックします。

## ファイル構成

```
index.html            画面構成
style.css             スタイル
app.js                軌道計算・等級・地図描画・時刻UI・タイミング計算
clips.js              保存したタイミングの管理
ar.js                 ARビュー（カメラ重ね表示 / 方位盤フォールバック）
world-land.js         世界地図データ（Natural Earth 110m land）
favicon.svg / .png    アイコン
apple-touch-icon.png  iOSホーム画面用アイコン
vendor/
  satellite.min.js    SGP4実装（satellite.js v5.0.0, MIT）
```
